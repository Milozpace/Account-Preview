# 新手配置指南

这页说明你需要准备什么、哪些步骤交给 Agent，以及怎样确认配置完成。Windows 示例使用 `D:\Account`，实际路径由你选择。macOS Apple Silicon 的安装命令由 Agent 按[开始使用](开始使用.md)执行。

## 1. 准备电脑和 Agent

需要 Windows x64 或 macOS Apple Silicon 电脑，以及能读取本地文件、执行命令的 Agent。使用你已熟悉的 Agent 即可，账号、模型和操作权限按所选软件配置。

Account 的项目文件夹就是账本长期保存的位置。Agent 能访问哪些位置取决于宿主软件的权限设置，选择工作区后仍要核对实际操作路径。

首次配置会下载项目 Python、依赖和 App，建议预留时间并保持联网。耗时取决于网络和电脑环境，配置手机同步时还需要本人操作手机。

## 2. 取得源码，选好长期目录

从[发布页](https://github.com/Milozpace/Account-Preview/releases)选择已发布版本，下载该版名称以 `-source.zip` 结尾的源码包。也可以把仓库地址交给 Agent，由它完成下载和校验。

将源码解压到长期保留的普通目录。打开后，应能直接看到 `README.md`、`AGENTS.md`、`bootstrap.ps1` 和 `release.json`。若文件都在解压后的子目录中，就把该子目录作为实际项目根，告诉 Agent 完整路径。已有账本所在目录应按原路径续接。

路径示例为 `D:\Account`。尽量选择稳定的本地磁盘位置，避开下载缓存、临时工作树、U 盘，以及会自动同步整份私人账本的目录。让 Agent 核对目录和发布来源后再开始配置。

## 3. 把配置任务交给 Agent

在 Agent 中打开项目目录，发送下面这段话。

```text
请帮我配置 Account Preview，仓库地址是 https://github.com/Milozpace/Account-Preview 。
先读 AGENTS.md、docs/开始使用.md 和 docs/Agent启动说明.md，核对我选定的绝对项目路径和已发布版本。
先检查是否已有账本，再准备同版环境、安装并绑定电脑版 App。确认是全新项目时才建立新账本。
先完成电脑本地使用，暂不配置手机和云端，也先不设预算。
需要我选择目录、月份、文件或处理系统授权时告诉我，已授权的步骤连续完成。
```

Agent 会准备项目专用 Python 和依赖，取得匹配的桌面组件，安装 App、绑定项目，并核对账本状态。普通使用运行预构建 App，所需运行环境按项目流程准备。

若宿主弹出命令或系统授权提示，核对正在操作的路径、发布来源和用途。登录密码、验证码、同步应用密码和系统安全授权由你在对应界面处理。

中途暂停后可以继续原会话。换会话时告诉新 Agent 项目路径和已经完成的步骤，让它通过本机状态续接。若想知道进度，可以说“现在到哪一步，还有哪些尚未完成？”

## 4. 准备一个月的账单

先选最近一个完整月，或你确实想整理的月份。在微信、支付宝各自的官方账单入口，按所选期间导出用于个人对账的流水。菜单名称和文件形式以平台当前提示为准。

若下载得到加密压缩包，由本人按平台或邮件中的说明解压，取得 CSV 或 XLSX。密码在本机处理。保留下载的原件，让 Agent 复制归档并核对文件哈希。

例如你把待处理文件放在 `D:\账单`，可以告诉 Agent 下面这段话，将月份替换成自己的选择。

```text
请处理 D:\账单 中我指定的微信和支付宝流水，期间是 YYYY 年 MM 月。
按随版记账 Skill 审核、入账并核验。用途明确的先完成，真实不明项集中说明。
```

说明具体文件和期间。文件覆盖不足时，结果只代表已提供的那部分记录。

## 5. 核对入账与 App 结果

Agent 使用项目随版的记账 Skill。你主要补充影响结果的用途或关联疑问，例如某笔付款是否属于代垫、退款对应哪笔原交易。确实不清楚可以说明待定。

打开 Account Preview，切到导入月份，核对收支、分类、日历和明细。新账本未设预算时显示“未设预算”，分类和分池消费仍可查看。需要额度时再进入[四池预算设置](四池预算设置.md)。

让 Agent 报告本批期间、新增/修改/重复笔数、净消费、收入及真实待确认项，并说明核验结果。App 未显示数据时，让它检查原项目路径、桌面绑定和本地快照。

## 6. 确认本地使用完成

- [ ] 取得了已发布的同版源码和本机平台组件。
- [ ] 项目环境、实际安装和桌面绑定分别核对完成。
- [ ] 本人账本核验通过，授权提供的文件已处理，并说明实际覆盖范围。
- [ ] App 能显示对应月份，分类和分池的待定项已说明。
- [ ] 知道账本、原件和备份的位置。

暂未提供账单时，交付状态可以是“环境与空库就绪，等待文件”。没有选择手机同步时，本地体验可以正常完成。首次查看后，Agent 可以用两三个问题了解你关心的支出，长期偏好经你确认后保存到本机。

## 常见停点

| 遇到的情况 | 下一步 |
| --- | --- |
| 下载失败 | 保留错误，让 Agent 重试官方发布来源，或手动下载同版 ZIP 和校验文件，按入门文档使用本地包 |
| 缺少 gh 或未登录 | 公开下载可匿名进行，Agent 按启动器的回退流程处理 |
| PowerShell 提示脚本受限 | 让 Agent 检查当前进程的执行方式，按入门指南处理 |
| 提示绑定了另一目录 | 先核对原目录归属，按明确的迁移授权处理，保留原配置 |
| 系统拦截安装或打开 | 核对下载来源、校验结果和具体系统提示，再由本人决定如何继续 |
| Agent 要求重新建库 | 先检查实际项目路径、来源配置和已有 SQLite |
| 已入账但 App 没变化 | 先查账本核验和本地快照，再查显示，按已发生的结果续接 |
| 程序更新失败或中断 | 按[更新与恢复](更新与恢复.md)检查恢复记录 |
| 需要他人帮助 | 按[反馈指南](反馈指南.md)准备脱敏信息，由你决定是否提交 |

## 以后怎么继续

日常告诉 Agent 本次账单在哪、要处理哪些期间，它会从[记账 Skill](../.agents/skills/account-maintenance/SKILL.md)继续。已批准的长期规则保存在本人项目里，单笔纠正按实际确认审计更新。

想在 Android 上查看或上传文件时，再按[手机与同步](手机与同步.md)连接现有账本。更新程序按[更新与恢复](更新与恢复.md)，导出与备份按[工作说明](工作说明.md#导出备份与恢复候选)。

账本和原件默认保存在本机，所选 Agent 可能将读取的内容发给云端模型。启用手机后还会使用坚果云加密中转。具体范围见[同步与隐私](同步与隐私.md)。
