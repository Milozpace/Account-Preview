# 新手配置指南：在 Windows 电脑上装好 Account Preview

> 给第一次用 Agent 的人。你只需要：点几下、复制粘贴、回答问题。  
> **所有命令都由 Agent 执行，你不用背命令。** 预计 40–90 分钟，大部分时间在等下载。

---

## 0. 先看这一页

**目标**：电脑上装好 Account Preview，用它看家里一个月的支出。

**你要做的 6 件事**

1. 装 DSH（Agent 软件）
2. 建一个项目文件夹，把项目放进去
3. 在 DSH 里打开这个文件夹
4. 把一段话粘给 Agent，让它自己配置
5. 回答它的几个问题，把账单文件交给它
6. 打开 Account Preview 看结果

**三个词先认识**

| 词 | 意思 |
|---|---|
| Agent | 会自己动手的 AI。你提要求，它读文件、执行命令、改配置 |
| 工作区（项目） | 一个电脑文件夹。Agent 只能在这个文件夹里干活 |
| 账本 | 记账数据，就是文件夹里的 `data\account.sqlite3`。**只在这台电脑上** |

**准备的账号**：一个 DeepSeek 账号（登录 DSH 用，没有就问哥哥要，或在登录页用手机号注册）。

---

## 1. 装 DSH

1. 浏览器打开 <https://www.deepseek.com/download/>
2. 下载 **Windows** 版（`dsh-latest-windows-x64.exe`）
3. 双击安装，一路「下一步」。**如果弹出管理员提示，叫家长点「是」**
4. 装完打开 DSH，用 DeepSeek 账号登录
5. 随便发一句「你好」，能回话就说明装好了

> 装不上、打不开：直接问哥哥，别自己找其他网站下载。

---

## 2. 建项目文件夹

**位置很重要**：选一个长期保留、不跟着网盘同步的目录，例如 `D:\Account`。

- ✅ `D:\Account`
- ❌ OneDrive 同步的目录、被 OneDrive 接管的桌面/文档（路径会变、会同步到云）
- ❌ U 盘、临时文件夹、`下载` 文件夹（会被清空）

**步骤**

1. 打开「此电脑」→ D 盘 → 新建文件夹，命名 `Account`
2. 浏览器打开发布页：<https://github.com/Milozpace/Account-Preview/releases>
3. 找到最新版（当前是 **v0.4.0-rc.1**），在 `Assets` 里下载：
   - **源码包**：`Account-Preview-0.4.0-rc.1-source.zip`（约 1.6 MB）
4. 右键这个 zip →「**全部解压缩**」→ 目标选 `D:\Account`
5. 打开 `D:\Account`，**应该直接看到** `bootstrap.ps1`、`release.json`、`README.md`、`docs` 等文件

> 如果解压后多出一层同名文件夹（如 `D:\Account\Account-Preview-0.4.0-rc.1\`），把里面的文件**全选剪切**到 `D:\Account`，让 `bootstrap.ps1` 直接在 `D:\Account` 下。

**自检**：`D:\Account\release.json` 存在，里面写着 `"version": "0.4.0-rc.1"`。

---

## 3. 在 DSH 里打开文件夹

1. DSH 左侧栏点「**添加工作区**」（或首次启动时点「**选择工作区**」）
2. 选择 `D:\Account`
3. 左侧出现 `Account`，点它，右边出现输入框

**这一步做对了，Agent 才能看到项目文件。**

---

## 4. 把任务交给 Agent

在输入框里粘下面这段（整段复制），回车发送：

```text
帮我在 Windows 上配置 Account：https://github.com/Milozpace/Account-Preview
先读 README.md、AGENTS.md、docs/开始使用.md，按官方流程来。
需要做：准备项目环境、安装并绑定 Account Preview 电脑版 App、建一个新账本。
我是第一次用，请每一步告诉我：现在在做什么、我需要做什么、大概等多久。
要我自己决定的地方就停下来问我，不要替我猜。
```

**发送后会发生什么**

| 阶段 | Agent 在做什么 | 你要做什么 |
|---|---|---|
| 读文档 | 读项目说明和官方流程 | 等一下 |
| 准备环境 | 下载 Python 3.12、装依赖到 `.venv` | 等（几分钟，全程联网） |
| 装 App | 下载桌面安装包、装到本机、绑定项目 | 等；可能弹权限框，点允许 |
| 建空账本 | 初始化数据库 | 等 |
| 问你问题 | 见第 6–7 节 | 回答 |

**关于「允许」弹窗**：Agent 执行命令前会弹确认（「允许 / 拒绝 / 始终允许」）。

- 允许 `D:\Account` 里的操作；装 App 时还会写系统里的配置目录（`LOCALAPPDATA`），这属于官方流程，也允许
- 除此之外看不懂的内容就点**拒绝**，然后把弹窗截图发给哥哥
- 「始终允许」只在你完全清楚它在干什么时点

**三条使用习惯**

- **不要关窗口**，也不要中途开新会话；在同一个会话里接着聊，它才记得前面做了什么
- Agent 说「完成了」时，让它把关键结果贴出来（`ok`、路径、笔数），别只看它说「好了」
- 想停下来，点停止按钮；想让它继续，直接说「继续」

---

## 5. 问它一个问题，确认它真的在干

配置过程中你可以随时问：

```text
现在到哪一步了？还有哪些没做？
```

它应该能报出：环境就绪 / App 装好并绑定 / 账本建好 / 还差账单。**答不出来或者含糊，就是没做完。**

---

## 6. 准备账单（最关键的一步，要家长配合）

Agent 会问：「你想整理哪个月？账单文件在哪？」

**推荐**：上一个完整月（比如现在是 11 月，就整理 **10 月**）。

**让家长在手机上导出账单**，导出到邮箱，再下载到电脑：

| 平台 | 路径（菜单名可能略有不同，认「下载账单 / 交易流水」） |
|---|---|
| 微信 | 我 → 服务 → 钱包 → 账单 → 常见问题 → **下载账单** → 用于个人对账 → 选时间段 → 填邮箱 |
| 支付宝 | 我的 → 账单 → 右上角 `···` → **开具交易流水证明** → 用于个人对账 → 选时间段 → 填邮箱 |

> 微信会发一个 **zip 压缩包**，**解压密码就在同一封邮件里**。别把邮件删了。

**文件放哪**：在 `D:\账单\` 建一个文件夹（自己建，不在项目里），把下载的 CSV / XLSX / ZIP 放进去。**原文件不要删、不要移动、不要用 Excel 打开另存**。

然后告诉 Agent：

```text
账单在 D:\账单\ 文件夹里，是 2026 年 10 月的。请开始整理。
```

---

## 7. 导入与核对

Agent 会：把原件复制归档 → 逐笔审核 → 分主分类和四个资金池 → 写入账本 → 核验。

**它会问你这些，照实答就行**

| Agent 问 | 你怎么答 |
|---|---|
| 哪个月、哪些文件？ | 「10 月，`D:\账单` 里那两份」（说清楚平台和月份） |
| 这笔是什么用途？（金额较大的不明支出） | 问家长，或直接说「**不确定，先待定**」 |
| 要不要现在设预算额度？ | 「**先不设**，先看支出」——这是官方默认，不设也能用 |
| 你们最关心哪块支出？ | 照实说，比如「吃饭」「孩子上学」「出行」 |
| 分类对吗？（它列出一批分类） | 只纠正明显不对的，不用逐条确认 |

**判断标准**：它说「完成」之后，问一句：

```text
报一下核验结果：账本总笔数、已分类和已分池的笔数金额、还有哪些待定、待定的原因。
```

四个资金池是：**运行账户**（日常通勤吃饭）、**随心消费**（娱乐）、**旅行/体验**、**成长/项目/耐用品**（学习、设备）。**没设预算也会有分池**，这是正常的。

---

## 8. 打开 App 看结果

1. 开始菜单搜 **Account Preview**，打开（窗口标题是「生活账本」，正常）
2. 切到你导入的那个月，应该能看到：净支出、分类占比、日历、明细
3. 顶部若显示「**未设预算**」，正常——现在是观察期，只记录不评判

**看不到数据**：先关掉 App 重开；还不行就回 DSH 说：

```text
App 里看不到刚导入的数据，请检查桌面绑定并重新验证。
```

---

## 9. 收尾（10 分钟）

Agent 会问两三个问题，比如「哪块支出最出乎意料？」「这些分类符合家里习惯吗？」。

- 你可以答「**不确定，先记着**」，这是允许的
- 只有你或家长**明确说「这条以后都这样」**，才会存成长期规则

**验收清单**（全打勾才算完）

- [ ] DSH 能正常对话
- [ ] `D:\Account\release.json` 存在，版本和发布页一致（现在是 `0.4.0-rc.1`，以后会变）
- [ ] Agent 跑完启动器，输出里有 `"ok": true`
- [ ] 本机已安装 Account Preview，能打开
- [ ] App 里能看到导入那个月的消费和分类
- [ ] 知道了「总笔数 / 待定笔数 / 待定原因」
- [ ] 账本位置记住了：`D:\Account\data\account.sqlite3`（**备份 = 关掉 App 后复制整个 `D:\Account`**）

## 10. 出问题怎么办

| 现象 | 怎么办 |
|---|---|
| 下载一直失败 / 超时（`504`、卡 0%） | 换时间重试，或改用手机热点；**别用第三方「加速站」下安装包**，来源不可信 |
| 解压后找不到 `bootstrap.ps1` | 解压多了一层文件夹，按第 2 节把文件挪到 `D:\Account` 根目录 |
| 提示「禁止运行脚本」 | 让 Agent 用 `-ExecutionPolicy Bypass` 重试，**不要改系统全局策略** |
| 提示找不到 `gh` / 未登录 | 正常。启动器会自动改走公开下载，不用装 GitHub 工具 |
| Agent 说安装包下载失败 | 浏览器手动下载 `Account-Preview-0.4.0-rc.1-windows-x64.zip` 存到 `D:\`，然后告诉它：「安装包在 `D:\Account-Preview-0.4.0-rc.1-windows-x64.zip`，用 `--bundle` 指向它」 |
| 卡在下载 Python 或依赖 | 保持联网，让 Agent **重跑同一条命令**，已完成的步骤会保留 |
| 提示「此身份已绑定另一个项目」 | **不要删配置**，把原话发给哥哥 |
| 「Windows 已保护你的电脑」 | 点「更多信息 → 仍要运行」；不确定就先问哥哥 |
| Agent 说缺账单密码 | 微信账单 zip 的密码在**同一封邮件**里 |
| Agent 反复说要重新建库 | 停下来，可能是走错目录了，找哥哥确认 `D:\Account` |
| App 打开白屏 / 闪退 | 重开；还不行让 Agent 跑一次诊断并把输出发出来 |

**卡住超过 15 分钟**，把这三样发给哥哥：**截图 + Agent 最后几行输出 + 你刚才发的原话**。

---

## 11. 不要做的事

- ❌ 不要在聊天、截图、群里发**密码、验证码、银行卡号、账单全号**
- ❌ 不要自己改 `data\`、`.runtime\` 里的文件，不要删文件夹里的东西
- ❌ 不要删账单原件（Agent 会复制一份归档，原件留着）
- ❌ 不要为了「让它显示好看」去改交易日期或电脑日期
- ❌ 不要把 `D:\Account` 传到网盘、GitHub 或发给别人
- ❌ 不要自己改项目源码来解决分类或显示问题

## 附录：给家长的隐私说明（一句话版）

账本、账单原件、规则都**只存在这台电脑**的 `D:\Account` 里，不上传。但 Agent 用云端模型时，它读到的账单内容可能被发送给模型服务处理；所以别把 `D:\Account` 整个目录分享出去。详见 [同步与隐私](同步与隐私.md)。
