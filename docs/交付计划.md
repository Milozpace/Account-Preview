# Account Preview 交付计划

## 目标与授权

最初建立独立、干净私有仓库（维护者已于 2026-11-01 公开，日常读取不再要求邀请或登录），朋友把 URL 给能读仓库、执行命令的任意本地 Agent，说“帮我配置”即可开始。不配置 Agent、不强制 Skill、不接入模型 API。默认先完成 Windows/macOS 本地 mini 体验，Android 与坚果云同步是后续可选扩展；普通用户预构建包，免 Rust/Node/Android 工具链。

不带个人数据、参数、身份或真实示例。最初独立仓库交付使用 `0.4.0-preview.1`（Tauri/Windows 数字版 `0.4.0`）；当前本地开发候选为 `0.4.1-preview.1`。历史发布授权不延用，本轮不自动创建 Release、标签或代写版本说明；真实改账、安装及云端发布按当次授权执行。开发验证通过后主动提交相关代码，不重复询问 Git 提交许可。

## 已确认设计

电脑 Agent 审核、事务写 SQLite，统一 Python 计算。Android 只读快照并加密投递原账单。保留身份隔离、双槽和加密协议，上传/收取/入账/发布/回执分验。

先由本人选择一个月本地账单，Agent 审核记账并在电脑查看，再做两三个简短访谈，了解关注的支出及不适配分类。第一版不要求开始前给出预算、完整分类或消费约束；完整个性化管理留待使用反馈后迭代。

首次导入必须按证据完成主分类和分池，不依赖预算是否制定；通用四池按用途使用，不按主分类、商户或金额机械映射。真实歧义才说明后待确认，不整批猜测、不硬凑覆盖率；报告已分配与未完成笔数、金额及原因，保留个人已确认例外和退款继承关系。无需提前完整访谈或设计分类体系。

新候选版 init 可省略 amounts，默认四池零额度、零滚存，仅新初始化账本记录 `budgetMode=zero-observation-v1` 并纳入业务哈希。观察期显示“未设预算”及“设置 → 四池预算”入口，真实分池消费可见，不产生超支、滚存欠账或安全积累；首次正数额度或明确非零初始滚存启用后，后续零额度仍按正常预算计算。已有未标记账本保留原计算及哈希，不根据零值推断、不自动迁移或改历史。四池固定键为运行账户、随心消费、旅行/体验、成长/项目/耐用品；额度可经本人预检确认从导入月生效，仍不支持任意自定义资金池。本轮不补改真实历史交易；版本仍为本地 `0.4.1-preview.1` 候选，后续编号与发布另待维护者确认。

单笔不自动变长期规则，访谈关注意向不自动变金额限制。高影响/重复歧义澄清、低影响合并询问或 Unknown；长期须批准条件、例外、来源、范围，不能凭金额或覆盖旧确认。

本机忽略文件 `local/档案.md`、`local/个人规则.md`、生成的 `PROJECT_MEMORY.md`。密码只进 App 原生界面，配对设备扫码不经聊天。标识 `com.account.preview`；配置在 Windows/macOS 用户目录的 `AccountPreview/project.json`，不回退生产路径。

bootstrap 准备托管 Python/.venv/锁定依赖、本机配置和匹配 Release，组件通过 `.runtime/helpers.json` 指向版本目录。macOS 可 ad-hoc，不承诺付费签名/公证，不全局绕过系统防护。

## 分阶段验收

| 阶段 | 交付 | 通过标准 |
|---|---|---|
| A 隔离 | 仓库、忽略、隐私扫描 | 无个人文件/作者路径/身份，原项目不变 |
| B 初始化 | 包装器/托管环境/doctor/init | 新目录空库、拒覆盖、默认零额度观察模式及未设预算说明、旧库计算/哈希不变、个人资料生成 |
| C 原生 | 独立标识、双平台绑定、helpers | 路径/架构匹配，无旧目录依赖，用户无需开发链 |
| D 文档 | 单入口、人类/Agent/规则/反馈 | 无历史上下文可读，边界清晰、示例合成 |
| E 合成 | 导入/审计/净额/预算/恢复 | 事务/幂等/哈希/隔离，失败留有效快照 |
| F 产物 | 三平台包/helpers/校验和 | 版本架构一致、可重现、macOS 限制准确 |
| G 本地体验 | 安装/绑定、本人首月账单、电脑查看、简短访谈 | 本地可用、有依据的主分类与分池及真实待定说明、预算未制定/已制定说明、同步未启用可正常完成 |
| H 可选手机与云 | 新身份/发布回读/手机/inbox | 本人选择后再配置，不借原身份，不重建账本，各环节分报 |
| I 发布 | Release/权限/朋友 Agent 演练 | 明确授权，产物可取，未验收透明 |

接口变化同步帮助与文档。合成测试不替代操作系统、设备、安全存储、真实服务。未选择手机与云端不阻塞本地完成，也不意味着该扩展已经验收；安装包覆盖升级保护另按发布检查验证。

隐私边界：默认原件、账本和规则在本机，不提交共享仓库；本人选用的 Agent 可能调用云端模型，可选手机投递会有坚果云加密副本。详细说明见同步与隐私，不能绝对承诺所有场景仅在本机处理。
