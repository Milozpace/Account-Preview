# 0.4.0-preview.1 本轮验证记录

本记录区分本机验证与外部验收。源码来自独立提取的新项目，不继承个人仓库历史；真实账本、原始账单、个人规则、凭据、缓存及签名私钥不包含在交付中。

## 已验证

- Windows 独立托管环境：固定 uv、Python 3.12.12、项目虚拟环境及依赖哈希检查。系统自带 PowerShell 5.1 和 PowerShell 7 均可运行；中文脚本使用 UTF-8 BOM。
- 新目录的空 SQLite 账本：预算、零初始滚存、默认预检、显式执行、重复初始化保护、中断恢复及空快照。
- 无历史上下文的独立 Agent 演练：从交付源码和 Windows bundle 开始，建立虚构用户账本和独立安全身份；重复配置保留身份、规则、配置和账本。
- 演练的两笔虚构账单：一笔消费和一笔非消费，净消费 12.50 元；审核入账后 revision=1，重复预检与执行均零新增、零修改。备份、审计、完整性与外键检查通过。全过程发布关闭。
- Windows 原生 App 158 项测试、安全存储插件 10 项、加密核心 24 项与 1 项文档测试、App 前端 175 项、共享网页 51 项、Android 插件 19 项通过。
- Windows 安装包和配套三种原生工具已构建；Android arm64 release APK 已构建、16 KiB 对齐和 v2/v3 签名校验通过。Android 标识为 `com.account.preview`，数字版本 `0.4.0` / 4000，与原应用分离。
- 原始金额缺失/占位符拒绝而非补零，CSV/XLSX prepare→审核→import 已有回归覆盖。
- 源码按路径白名单导出，已知敏感模式扫描通过；源码 ZIP 为 shell 文件保留执行位。使用源码包也可通过 `sh bootstrap.sh` 启动。

完整 Python 测试数量以本次最终测试输出为准；存在一项默认关闭的合成 Excel COM 兼容测试，不属于 SQLite 使用链路。

## 待验收

- 新私有仓库的提交、上传、构建与 Release：按已授权交付计划继续执行；用户于 2026-10-31 明确修正为验证后主动提交 Git。实际仓库与构建结果尚未写入本记录前，不宣称远端完成。
- macOS Apple Silicon / Intel 的构建与原生测试：工作流已提供，尚未在 Mac runner 执行。Keychain、保存/取消窗口、首次打开和真实安装仍需 macOS 证据。
- Windows 安装包的实际安装/GUI、Android 手机安装与文件选择器、配对保持和升级；构建成功不等于上述行为已验收。
- 独立用户的真实坚果云配置、回读、手机查看、上传账单、收取入账与回执：本轮未访问真实云端，也未使用真实账单。

Mac 或设备缺失时不能将工作流文件、模拟测试或旧版本验收替代为本版本通过。若后续获准发布，先更新本记录，再以实际产物和日志为依据报告。
