## 分发包检查

- Windows ZIP 和 Mac ZIP 各包含一个对应架构安装程序及三种匹配的原生辅助工具；逐文件检查清单、哈希与 PE/Mach-O 架构，不混用旧版 `.runtime` 产物。
- Mac 在对应架构的 macOS runner 构建，使用 ad-hoc 签名；实际首次打开与用户授权未由构建代替。
- Android 最终 APK 由 CI 候选通过独立预览密钥签名，标识 `com.account.preview`，数字版本 `0.4.0` / 4000，只有 arm64-v8a。v2/v3 签名、ZIP 16 KiB 对齐及所有原生库 ELF LOAD 段 16 KiB 对齐通过。私钥和密码不随包分发。
- 源码 ZIP 只含白名单内容，为 shell 文件保留执行位；也支持 `sh bootstrap.sh`。源码、各平台包与校验文件从私有 Release 分发，发布状态以 Release 页为准。
