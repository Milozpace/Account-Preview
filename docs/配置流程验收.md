# 首轮配置反馈处理记录（2026-11-01）

> 历史资料。保留当时的计划、版本和验收范围，后续状态以实际发布/安装证据为准。当前操作入口见[文档导航](README.md)。

本记录对应首轮本机实测的13项反馈，只记通用问题和处理结果，不包含测试者的真实交易、预算或本机路径。修复基于未发布的 `0.4.1-preview.1` 候选；已有 `0.4.0-preview.1` 安装包不会随源码提交自动改变。新安装包构建与设备验收留到发版准备，版本说明和发布仍由维护者决定。

|---|---|
| 1. 初始化提示冲突 | bootstrap、doctor、init 使用 mini 技术零占位/零滚存说明；已有账本保留，不再建议重复初始化。onboarding 回归覆盖新库与已有库提示。 |

| 3. 审核字段隐藏约束 | [数据字典](数据字典.md#审核字段取值)写明非零金额的三种英文口径、零值限制、事件自由文本、资金池及派生类型，并提供虚构字段片段。未放宽账本校验。 |

| 6. 绑定冲突无出口 | 新增显式 `--rebind-from OLDROOT`，核对旧根，原字节备份后切换；默认仍拒绝冲突。回归覆盖错误旧根、备份、重复执行及检查期间配置变化。须关闭 App 单独操作，锁不覆盖其他写入器。 |

| 8. 重跑行为不明确 | 区分重新同步依赖、组件哈希校验、相同绑定 unchanged、显式安装再次执行；不会自动重新建库。 |
| 9. 共存隔离难核对 | 开始使用列出 personal/preview 应用名、标识、默认安装位置、绑定与安全存储命名空间；公开仓库不改变本地隔离。 |
| 10. steps 不区分执行 | 输出 python/components/desktop/app/native 的 requested 与 planned/completed/unchanged/skipped；测试验证未选择与显式重跑。 |

| 13. 桌面同步入口不可达 | 应用设置 → 一般 → 手机与同步，复用原同步表单和返回路径。测试覆盖空快照/合成快照及键盘来源；真实浏览器配合受限 native mock 验证进入与返回，没有保存密码、生成二维码或云端调用。 |

本轮验证：Python unittest 299 项，2 项因平台跳过；App 17 个测试文件共181项通过，TypeScript/Vite 构建通过。PowerShell5.1 管道及 POSIX 脚本语法/错根检查包含在上述测试中，不再重复全量执行。源码版本校验、发布文件白名单和已知敏感模式扫描通过；历史扫描仍有需人工复核的二进制，不把自动扫描说成全面隐私保证。独立审查发现的 doctor 字段笔误已修正，改绑并发边界已写明。

本轮没有安装覆盖现有 App、操作真实账本/凭据/配对或发布 Release；浏览器 mock 不是 Windows/Mac 原生设备与手机同步验收。仓库公开后只读获取无需身份认证，推送和发布仍需要维护权限；历史 `private-preview` 频道值仅用于现有更新协议兼容。
