# 文档导航

按本次要做的事选择入口。首次使用者先读新手指南，Agent 按开始使用配置。已有账本的日常记账直接进入随版 Skill。

## 使用与操作

| 现在要做的事 | 入口 | 读完后应能完成什么 |
| --- | --- | --- |
| 第一次接触，想知道自己要准备什么 | [新手配置指南](新手配置指南.md) | 选择目录、准备账单、把配置任务交给 Agent |
| 由 Agent 安装并建立本人账本 | [开始使用](开始使用.md)、[Agent 启动说明](Agent启动说明.md) | 核对版本和根目录，完成电脑本地体验 |
| 导入新账单、收取手机文件、纠正已入账记录 | [记账 Skill](../.agents/skills/account-maintenance/SKILL.md) | 审核、入账、核验并说明待定项 |
| 确认目录、原件、导出与备份的用途 | [工作说明](工作说明.md) | 找到本人数据并安全归档、导出或备份 |
| 设置四池额度 | [四池预算设置](四池预算设置.md) | 预览生效月和影响范围，再确认保存 |
| 让 Agent 记住本人偏好 | [规则与学习](规则与学习.md) | 区分单笔纠正、关注点与已批准长期规则 |
| 连接 Android、查看或上传账单 | [手机与同步](手机与同步.md) | 继续现有账本，配置配对与同步并逐步核验 |
| 了解数据经过哪些设备与服务 | [同步与隐私](同步与隐私.md) | 确认本地、所选模型服务与可选云端的处理范围 |
| 更新程序、处理升级中断 | [更新与恢复](更新与恢复.md)、[版本衔接指引](版本衔接指引.md) | 更新匹配组件，重读流程，检查尚未完成的跨版事项 |
| 遇到问题，需要反馈 | [反馈指南](反馈指南.md) | 定位失败环节，提供脱敏且可复现的信息 |

## 文档版本如何选择

首次配置先读默认分支的最新入口，再取得所选已发布 Release 的同版源码与平台包。执行参数和功能以该固定源码为准。

已有安装更新后，通用文档从更新结果 `releaseDocs` 指向的源码目录读取。使用根里的 `docs/`、`AGENTS.md` 和本人档案可能保留旧版内容，继续用于所有者约定与批准依据。Preview 使用同版官方 Skill，personal 的本机 Skill 处理按[更新与恢复](更新与恢复.md#skill-冲突如何处理)。
