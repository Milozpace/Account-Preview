# Agent 启动检查

这是给接手 Agent 的简短清单。人类首次使用仍从[开始使用](开始使用.md)进入。

1. 读取根目录 `AGENTS.md`、README 和开始使用，确认本项目绝对根路径及本次授权。
2. 私有 URL 必须已有本机认证；不能向用户索取聊天中的令牌、密码或配对截图。没有权限先说明具体登录步骤。
3. 按配置授权执行 bootstrap：准备 `.venv`、匹配 Release bundle/helpers、安装及桌面绑定。Windows 用 `.\bootstrap.ps1`，macOS 用 `sh ./bootstrap.sh`。随后托管 Python 执行 doctor。
4. 未初始化时询问生效月与四池额度，默认零滚存，预检后初始化、verify，再 `account.py --root ROOT refresh --apply` 生成本机空快照；此时保持发布门禁关闭。已有账本读本机档案、规则、记忆，不覆盖初始化。
5. 匹配 helper 就绪后执行 `PY bootstrap.py --apply --initialize-identity`。该命令先查原生状态、幂等创建尚不存在的安全身份，不上传；不要重复直接执行原生 `--init`。
6. 指引用户分别在电脑/手机原生设置输入 WebDAV 信息及每台设备各自的应用密码，再由电脑显示 QR、手机扫码。电脑密码不会通过 QR 传到手机，秘密和 QR 均不进聊天。
7. 已明确获准首次测试同步时，执行 `PY bootstrap.py --apply --enable-publish`，开启原生与本地双门禁但不上传；再执行 `account.py --root ROOT refresh --apply`，检查真实加密上传/云端回读，最后手机刷新。已授权的配置步骤连续完成，不重复确认；未授权云端时完成本机准备并列待办。
8. 业务写入按[工作说明](工作说明.md)审核、预检、提交及核验，按[规则与学习](规则与学习.md)保护单笔确认。已授权开发验证后主动提交相关代码；配置、真实改账、云端、配对与远端操作按任务实际授权，不重复询问已授权事项。
9. 分别报告本机环境、账本、快照、身份、双端配置、安装、双门禁、云端和设备实测，无环境/设备不声称验收。
