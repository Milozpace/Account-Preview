# 工作说明

日常记账统一读取仓库内的 [account-maintenance Skill](../.agents/skills/account-maintenance/SKILL.md)，包括本地/手机来源、批量解析、审核、入账、纠正、核验和结果报告。本文件只说明目录与任务边界，不重复维护第二套日常流程。常规记账无需先读完整入门、更新或规则学习文档。

| 位置 | 职责 |
|---|---|
| `data/account.sqlite3`、`data/source.json` | 唯一当前账本及明确来源选择 |
| `sra/` | 原始账单，只读保留；归档见下文 |
| `local/档案.md` | 本机实际状态、用途与偏好 |
| `local/个人规则.md` | 本人明确批准的规则和边界 |
| `PROJECT_MEMORY.md` | 本机状态/证据指针，不是用户批准依据 |
| `.runtime/` | 审核候选、恢复副本、快照、组件及同步状态 |
| `.agents/skills/account-maintenance/` | 同版官方日常记账 Skill 与必要参考 |
| `docs/` | 可分享的产品、配置和契约说明 |

缺少个人档案或记忆不表示账本未初始化，以 doctor、来源配置和 SQLite 检查为准。不能因缺文档重建账本或找别人资料补齐。私人资料、账本、原件、缓存、凭据和产物不提交，不删除原件或清空 `.runtime`。

## 原件归档

核对本人选定的 ROOT，在其 `sra/` 下归档，不使用符号链接或 junction。只复制授权处理的文件，保留下载夹等原文件，不移动、不重存或改编码。对来源复制前后和归档文件核对 SHA-256；复制期间来源变化就停止核对。同名同哈希可复用，同名不同字节另取明确文件名（如加哈希后缀），不覆盖旧件。私人文件名不进共享文档或 Issue。

prepare 使用归档绝对路径并保留审核 JSON 的 `source_files` 路径与哈希。手机工具已校验归档的文件直接使用工具返回路径，不另制不同字节的原件。详细执行及失败续接由日常 Skill 负责。

## 其他任务

首次环境和空库配置按 [开始使用](开始使用.md)、[Agent 启动说明](Agent启动说明.md)，首批账单交给日常 Skill；电脑本地可用后再按需要做 [规则与学习](规则与学习.md) 的简短访谈。缺预算不阻塞有依据的分类分池；观察模式、正式额度及滚存按 [四池预算设置](四池预算设置.md)，不用零额替代未知交易金额。

程序更新按 [更新与恢复](更新与恢复.md)，手机扩展按 [手机与同步](手机与同步.md)，共享开发按 [开发同步与发布规范](开发同步与发布规范.md)。普通使用者通过正式工具和发布程序工作，不修改共享源码处理个人分类或预算。账本、快照、云端、回执、设备结果分别报告，命令成功不等于全部验收通过。
