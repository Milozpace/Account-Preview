# 工作说明

本页说明目录、文件和工具的职责。日常导入、手机收件、分类纠正和核验统一从[记账 Skill](../.agents/skills/account-maintenance/SKILL.md)进入，完整业务取值见[数据字典](数据字典.md)。

## 目录与数据来源

| 位置 | 职责 |
| --- | --- |
| `data/account.sqlite3` | 唯一当前账本 |
| `data/source.json` | 明确选择当前 SQLite 来源 |
| `sra/` | 原始账单的本机归档，保留原字节 |
| `local/档案.md` | 本人的实际使用状态、关注点与偏好 |
| `local/个人规则.md` | 本人已批准规则、适用范围及依据 |
| `PROJECT_MEMORY.md` | 本机状态/证据指针，使用前核对 |
| `.runtime/` | 审核候选、恢复副本、快照、组件及同步状态 |
| `.agents/skills/account-maintenance/` | 日常记账 Skill 及必要参考，管理策略依身份和版本 |
| `docs/` | 产品指引与契约，更新后的同版副本见 releaseDocs |

缺个人档案或记忆时先检查实际库和来源，再补状态指针。更新保护所有者文件的范围见[更新与恢复](更新与恢复.md)。

## 原件归档

核对本人 ROOT，在 sra 下归档授权文件，目录采用普通本地路径。保留下载原件，复制归档时核对来源复制前后与归档文件的 SHA-256。复制期间来源发生变化时先核查。

同名同哈希文件可复用，同名不同内容另取明确名称。手机工具已校验归档的文件采用其返回路径。本批 prepare 使用归档绝对路径，保留 source_files 的路径与哈希。

原件、私人文件名、审核内容和缓存留在本机。详细写入与失败续接按记账 Skill 执行。

## 常用操作的影响

命令模板中的 PY 为本项目 Python，工作目录为 ROOT，所有路径由 Agent 核对后引用。

| 操作 | 实际影响 |
| --- | --- |
| doctor / inspect / verify / find-records | 本机检查或有限查询 |
| prepare | 写新的审核候选文件，账本保持原状 |
| import 预检 | 校验审核候选与来源 |
| import --apply | 事务写入，成功后可能生成展示、按门禁发布并尝试回执 |
| refresh --apply | 核验并更新展示，可能按门禁发布 |
| app_desktop.py restore-local | 仅从当前账本重建本地 App 展示 |
| budget-set --apply | 保存已确认额度并生成本地展示 |
| backup / export-excel | 立即写新输出文件，这两条没有 apply 参数 |
| restore --apply | 写全新恢复候选，当前来源保持原状 |

同步门禁要核对本地配置和实际原生状态，doctor 不证明两者。已有云端授权的范围在业务执行前确认。

## 导出备份与恢复候选

App 可将所选月的当前缓存汇总和明细导出为 Markdown。导出范围随有效快照，数据完整性结合账单实际覆盖判断。需要表格时从 SQLite 生成 Excel 查看副本。

```text
PY scripts/account.py --root ROOT export-excel --output ROOT/exports/本次导出.xlsx
PY scripts/account.py --root ROOT backup --output ROOT/local/backups/本次备份.sqlite3
```

使用全新输出路径。账本备份通过 SQLite Backup API 取得一致副本，保留返回的 sourceHash 和日期。备份账本之外，还需按恢复目标妥善保存原件、个人规则和配置；安全身份与凭据的恢复另按其原生机制处理。

从已有副本先查看恢复计划，再创建全新候选。当前 restore 不带 apply 时仅返回目标是否存在，备份有效性仍须核验，并由实际创建过程检查。

```text
PY scripts/account.py --root ROOT restore --input ROOT/local/backups/本次备份.sqlite3 --output ROOT/local/recovery/恢复候选.sqlite3
PY scripts/account.py --root ROOT restore --input ROOT/local/backups/本次备份.sqlite3 --output ROOT/local/recovery/恢复候选.sqlite3 --apply
```

候选建立后核对完整性、关联、期间、修订和汇总，比较备份之后是否还有新入账。替换当前来源由本人在审阅核对结果后明确授权。程序更新的恢复日志见[更新与恢复](更新与恢复.md#失败与中断)。
