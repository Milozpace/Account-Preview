# 云端目录隔离修复验收（2026-11-02）

## 结果与范围

修复 preview 与 personal 共用硬编码 Account 根目录的问题。按精确构建身份
选择目录：preview 为 Account-Preview，personal 保留 Account；ledger、probe、
inbox 统一选路，诊断与 standalone helper 使用相同编译身份。未知身份拒绝构建，
不根据显示名称猜测，不接受任意输入路径，不回退访问旧云目录。

旧 preview 凭据配置可只读沿用，实际请求固定使用新目录；身份、配对、密钥、
缓存及发布门禁不重置。preview 的发布确认与恢复 intent 使用新文件名，旧文件
原样保留，避免把旧目录的已发布或覆盖授权误用于新目录。新 scope 的待发版本
高于保留缓存；正式账本发布还在直接待发入口检查版本下限。synthetic probe
已有确认轮次保留既有历史 fixture 的精确密文重试语义。
