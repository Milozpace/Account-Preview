# 开发与合成数据

普通用户运行预构建 App 和托管 Python；开发者按锁文件准备 Node/Rust/Tauri，Android 构建才需 JDK/SDK/NDK。不要求朋友为首次使用搭完整工具链。

## 隔离与运行

用独立工作副本和临时根目录，先读 `AGENTS.md`。测试不读个人主账本、其他项目、`local/`、真实安全存储/云端。只生成合成记录，不复制真实 fixtures；来源、身份、金额、ID 明确为测试。

Python 依赖由 bootstrap 固定，项目解释器执行：

```text
PY -m unittest discover -s tests -p "test_*.py"
```

前端在 `app/` 执行 `npm ci`、`npm test`、`npm run build`；原生在对应 Cargo workspace 执行 `cargo test --locked`。平台构建以 workflow/清单为准，无作者目录依赖。结果列范围，缺 macOS 或设备标待验收。

## 核心回归

- 全新目录 init、拒绝覆盖、预算键/金额/月份、默认零滚存、双平台项目绑定。
- 合成 CSV/XLSX → prepare → 审核 → 预检 → apply → verify，重复无新增/更新。
- 原始冲突、缺金额、重复订单、回退身份、退款/报销/分摊、整批回滚、写前备份、恢复候选。
- 四池重置/带符号滚存、生效月、Unknown/结构性排除、历史重算、sourceHash。
- 发布失败保留缓存、认证/身份拒绝、双槽回读、inbox 限额/去重/回执幂等。
- 覆盖安装保护账本、配置、密钥、配对和偏好；mock 不计真机或云端验收。

人工规则演练：单笔不推广，高影响/重复歧义澄清，金额相等不单独关联，规则不覆盖旧确认。用虚构场景；纯文档审查不证明所有 Agent 均遵守。
