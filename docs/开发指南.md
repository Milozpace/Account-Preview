# 开发与合成数据

普通用户运行预构建 App 和托管 Python；开发者按锁文件准备 Node/Rust/Tauri，Android 构建才需 JDK/SDK/NDK。不要求朋友为首次使用搭完整工具链。

本仓库是共享源码的唯一开发来源。公开交付以 release.json 为版本输入，personal 使用本机独立版本配置，两者均记录固定源码提交。npm/Cargo/Tauri/dashboard/Python 元数据由对应工具生成。具体版本政策见[版本与分支管理](版本与分支管理.md)。

纯文档任务核对 CLI 参数、链接、版本和代表性操作，运行受影响工具的已有回归。涉及行为变化时补充能复现问题的验证，具体范围按本轮改动确定。

## 隔离与运行

用独立工作副本和临时根目录，先读 `AGENTS.md`。测试不读个人主账本、其他项目、`local/`、真实安全存储/云端。只生成合成记录，不复制真实 fixtures；来源、身份、金额、ID 明确为测试。

Python 依赖由 bootstrap 固定，项目解释器执行：

```text
PY -m unittest discover -s tests -p "test_*.py"
```

前端共享源码需要两处依赖。从仓库根依次执行 `npm --prefix dashboard ci`、`npm --prefix app ci`，再分别运行两处的 `npm test` 和 `npm run build`。原生在对应 Cargo workspace 执行 `cargo test --locked`。平台构建以 workflow/清单为准，无作者目录依赖。结果列范围，缺 macOS 或设备标待验收。

## 核心回归

- 全新目录 init、拒绝覆盖、预算键/金额/月份、默认零滚存、双平台项目绑定。
- 合成 CSV/XLSX → prepare → 审核 → 预检 → apply → verify，重复无新增/更新。
- 原始冲突、缺金额、重复订单、回退身份、退款/报销/分摊、整批回滚、写前备份、恢复候选。
- 四池重置/带符号滚存、生效月、Unknown/结构性排除、历史重算、sourceHash。
- 发布失败保留缓存、认证/身份拒绝、双槽回读、inbox 限额/去重/回执幂等。
- 覆盖安装保护账本、配置、密钥、配对和偏好；mock 不计真机或云端验收。

人工规则演练：单笔不推广，高影响/重复歧义澄清，金额相等不单独关联，规则不覆盖旧确认。用虚构场景；纯文档审查不证明所有 Agent 均遵守。

接口变化同步帮助、指南、字典、脚本和测试，完成任务更新共享交接状态；实施草案留忽略的 local，正式规范随代码提交。按[发布检查](发布检查.md)交付，无个人账本、原件、规则、缓存、凭据或真实验收材料。开发验证通过后主动提交本次相关代码；新 Release 先由 Agent 起草说明，由维护者确认该版发布及最终文案。仓库可见性变化另按规范检查与确认。
