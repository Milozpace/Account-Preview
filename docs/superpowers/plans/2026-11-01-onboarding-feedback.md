# 首轮实测配置反馈修复实施计划

> **For agentic workers:** 使用 subagent-driven-development 独立实现、两阶段审查与集成验证。用户已明确要求继续开发并以本机反馈记录为问题范围；连续完成，不重复询问开发许可。测试数据、凭据、配对和已安装 App 不操作，发布说明和新 Release 仍由维护者确认。实施中维护者已将仓库公开，获取流程调整为匿名可用；按最新要求避免重复全量验证，本轮不构建安装包。

**Goal:** 闭合首轮实测的13项引导和产品阻碍，让新用户Agent按文档完成本地mini及可选同步，而不靠猜测和未记录的绕路。

**Architecture:** 恢复从桌面设置进入现有同步页面；沿用凭据表单/二维码及同步协议。启动器增加明确目标根校验、可审计重绑、结构化执行状态，并修复PowerShell5.1 stderr捕获。初始化保持技术零占位；通用说明按实际代码与仓库可见性修正，不引入无预算UI或重写预算历史。

**Tech Stack:** 现有TypeScript/Vitest/Vite/Tauri，Python标准库/unittest，PowerShell5.1及POSIX启动器。
