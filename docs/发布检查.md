# 预览发布检查

面向维护者，每次留版本、构建来源、产物、SHA-256、系统/架构、时间及通过/失败/未执行项。清单不能替代实测。

- [ ] 包无个人账本/原件/档案/规则/记忆、真实缓存/日志、凭据/生产身份。
- [ ] 忽略和隐私扫描覆盖数据库 sidecar、导出、备份、缓存、产物、安全配置。
- [ ] Python 固定依赖、前端/Rust 锁文件可重现，合成测试与构建通过。
- [ ] `0.4.0-preview.1` / 数字版 `0.4.0` 一致，各平台和 helpers 架构/名称匹配。
- [ ] Windows 新目录引导、doctor、init、verify、安装/绑定/启动。
- [ ] macOS 同上，路径/权限/签名/首次打开实测。
- [ ] 合成导入/去重/冲突/回滚/备份恢复、个人隔离、旧确认保护。
- [ ] 双端覆盖安装保留配置/密钥/配对/偏好，文件选择/取消实测。
- [ ] 独立身份实测发布回读、手机刷新、账单投递/收取/入账/回执。
- [ ] 多用户/根互不覆盖，无模型 API 或必装 Skill 假设。
- [ ] 无历史上下文 Agent 演练，缺权限/产物/配置准确报告。

未执行标待验收，单平台构建不代替跨平台/真机。未发布不编造地址。已授权开发验证后主动提交相关代码，不另询问提交许可；远端推送与发布按任务实际授权，已授权事项连续完成。

## Android 签名与构建产物

CI 的 Android artifact 是未签名构建候选；维护者验证后用同一份离线维护的预览版签名密钥签名，再生成最终 APK 的校验值和分发包。签名私钥及其密码不进入源码、Artifact 或 Release。预览版使用独立应用标识和签名，不能拿生产版密钥或配对来代替。

后续覆盖升级沿用首次分发的签名；协作者提交代码不代表各自创建不同签名的安装包。不要将 CI 的 unsigned 文件作为朋友可直接安装的版本。
