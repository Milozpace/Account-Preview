# 内部预览更新与恢复

先读版本说明。安装、云端、重新配对、改账、Git 分别按授权；更新 App 不表示同意重建账本/身份。

## 更新

1. doctor、inspect、verify，记录根、修订、哈希和版本，用 SQLite Backup API 备份。
2. 保留配置、安全存储、配对、偏好和有效快照，不清空 `.runtime` 或卸载删除用户数据。
3. 校验 Release 来源、版本、系统/架构和 SHA-256，安装对应包；helpers 匹配该版。
4. 再 doctor/verify，确认账本未因安装改变，检查启动、配置、配对、快照。迁移先在候选副本验证。
5. 按授权测刷新/云端/设备；未连接手机不算安装或真机通过。

macOS 内部包可仅 ad-hoc 签名，首次对单个 App 系统放行，不全局关闭防护；不承诺付费签名/Apple 公证。

## 故障与恢复

路径/Python 错先修独立绑定，依赖错按 bootstrap 修环境，缺组件取得匹配 Release。云端故障留本机结果，查认证/配置/网络，不默认重置身份。

看 `backup --help`、`restore --help`。备份经 SQLite Backup API，恢复到全新候选，禁止覆盖当前库/已有导出。核验完整性、ID/关联、出处、修订、净额、预算，与当前库对比，说明恢复/丢失期间及笔数。明确获准替换来源后才切换，留原库和依据。

App 回退须确认数据库/协议兼容，回退二进制不回滚已提交业务。恢复后分别验本机、快照、云端、设备，记录实测。
