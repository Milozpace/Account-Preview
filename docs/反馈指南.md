# 反馈问题

保留有效账本与快照，不重复写入或反复配对。Agent 收集脱敏诊断后提交私有 Issue，真实金融文件不上传。

提供系统、CPU 架构、App/Release 版本、位置、复现步骤、预期/实际、影响环节及 doctor/verify 脱敏结论。优先最小合成样本。

不附 SQLite、真实账单、完整审核、`local/`、`PROJECT_MEMORY.md`、`.runtime/` 整目录、安全存储、密码/令牌、配对二维码、完整订单/账号。截图遮姓名、明细和路径用户名；日志删凭据和真实交易。

分清提交、快照、云端回读、回执、手机显示；已提交不为同步问题再导入。留安全错误码、时间、修订，敏感原件仅本机。

使用[问题模板](../.github/ISSUE_TEMPLATE/bug_report.yml)或[建议模板](../.github/ISSUE_TEMPLATE/feature_request.yml)。反馈不授权改账、安装或云端发布。
