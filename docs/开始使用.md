# 开始使用

准备 Windows 或 macOS 电脑、能读私有仓库并执行命令的本地 Agent，以及 Android 手机。模型由所选 Agent 提供；Account 不配置模型 API。普通用户安装预构建包，不需要 Rust、Node 或 Android SDK。

## 1. 仓库访问

先给自己及 Agent 的本机身份配置私有仓库读取权限，再提供 URL 和 README 提示词。使用已认证 Git 或 GitHub CLI；私有 URL 本身不赋予权限。先完成平台登录或 SSH 授权，不向聊天贴令牌/密码。也可自行下载，再让 Agent 操作本地目录。

Agent 让你选择一个长期保留的普通目录，用常规 clone 或源码包解压建立项目，记录绝对根路径并读 `AGENTS.md`，不指向现有账本。正式账本不能放在临时 Git worktree、`worktrees` 或 `archive` 目录；开发工作树仅使用合成数据。预览标识 `com.account.preview`，与生产 App 的配置和身份隔离。

## 2. 托管环境与发布包

Windows 在 PowerShell 使用 `.\bootstrap.ps1`，macOS 使用 `sh ./bootstrap.sh`。默认只检查，`--apply` 执行。包装器自动用 uv 准备固定版本 Python、项目 `.venv` 和锁定依赖。详细参数见 `bootstrap.py --help`；完成托管环境后可用项目 Python 查看。

```text
.\bootstrap.ps1 --apply
sh ./bootstrap.sh --apply
```

以上按自己的系统选一条。下载预构建产物时加 `--repo OWNER/REPO --tag v0.4.0-preview.1`，要求 `gh` 已有私有仓库认证；也可先用已认证 `gh release download` 取得对应平台发布 bundle，再用 `--bundle ZIP路径`。`--configure-desktop` 写入预览 App 项目配置，`--install-app` 安装匹配包。这些标志可合并，一次准备环境、取得包、安装并绑定：

```text
.\bootstrap.ps1 --apply --repo OWNER/REPO --tag v0.4.0-preview.1 --configure-desktop --install-app
sh ./bootstrap.sh --apply --repo OWNER/REPO --tag v0.4.0-preview.1 --configure-desktop --install-app
```

替换自己的私有仓库并按系统选一条；未发布、无权限或架构不匹配时标待完成，不用其他项目旧包替代。确切行为以帮助与发布说明为准。若 Windows 执行策略阻止脚本，可由 Agent 使用仅针对当前进程的 PowerShell 启动方式，不更改全机策略。

下文 `PY` 为项目 Python：Windows `.venv\Scripts\python.exe`，macOS `.venv/bin/python`；`ROOT` 为本项目绝对目录。Agent 替换占位符、引用含空格路径：

```text
PY scripts/account.py --root ROOT doctor
```

核对根目录、Python、SQLite、依赖、原生组件和桌面配置。未配置云端不等于云端验收完成。

## 3. 预算与空库初始化

先询问生效月份和四池月额度：`运行账户`、`随心消费`、`旅行/体验`、`成长/项目/耐用品`。单位元、非负，不照搬模板。池的个人适用场景可调整，键名固定。

将[额度模板](../templates/预算额度.json)复制到 `local/预算额度.json` 并填入确认值。初始滚存默认全零；有历史依据时仅旅行/成长可带正负号，运行/随心必须零，滚存不是银行余额。自定义时用[滚存模板](../templates/初始滚存.json)。

```text
PY scripts/account.py --root ROOT init --effective YYYY-MM --amounts local/预算额度.json
PY scripts/account.py --root ROOT init --effective YYYY-MM --amounts local/预算额度.json --apply
PY scripts/account.py --root ROOT verify
PY scripts/account.py --root ROOT refresh --apply
```

先预检，已获初始化授权时继续执行。自定义滚存两条 init 都加 `--initial local/初始滚存.json`。创建空库、SQLite 来源、本机资料与记忆；已有账本拒绝覆盖。verify 后执行 refresh 生成空账本的本机展示快照。此时保持发布门禁关闭，不上传云端。

## 4. 安装与本机绑定

安装当前 Release 匹配系统/CPU 架构的电脑包及 Android APK。

手机可在浏览器登录已有访问权限的 GitHub 账号，从[当前私有 Release](https://github.com/Milozpace/Account-Preview/releases/tag/v0.4.0-preview.1)下载 `Account-Preview-0.4.0-preview.1-android-arm64.apk`；也可由电脑下载并按 `SHA256SUMS` 校验后，经 USB 或本人选择的文件传输方式交到手机。点开 APK，按 Android 系统提示完成本来源的安装授权与安装。Agent 先确认手机支持 arm64，再引导本人操作；未连接设备时不能报告已安装。

电脑包包含安装程序和匹配的原生工具，通常由 bootstrap 自动安装和放置。手动安装不会代替 `--configure-desktop` 的本机账本绑定。桌面配置位置如下：

| 系统 | 预览配置位置 |
|---|---|
| Windows | `%LOCALAPPDATA%/AccountPreview/project.json` |
| macOS | `~/Library/Application Support/AccountPreview/project.json` |

配置指向本项目绝对根与 `.venv`，无作者路径或生产回退。组件由 `.runtime/helpers.json` 原子清单指向 `.runtime/bin/<版本-平台>/bin/` 下匹配版本的 helpers；Windows 文件带 `.exe`。不要手动混用不同版本发布器。

macOS 内部预览使用 ad-hoc 签名，未经 Apple 公证，签名方式见 [Tauri 官方说明](https://v2.tauri.app/distribute/sign/macos/)。首次打开被阻止时，由本人按 [Apple 官方步骤](https://support.apple.com/en-us/102445)在“系统设置 → 隐私与安全性”中，为刚尝试打开的 **Account Preview** 选择“仍要打开”，再确认打开；只保留此 App 的例外，不关闭 Gatekeeper。来源不明确、文件损坏或提示恶意软件时保留现场并停止。

## 5. 建立桌面安全身份

SQLite 初始化不创建 App 安全身份。完成组件安装、空库核验与本机快照后，执行：

```text
PY bootstrap.py --apply --initialize-identity
```

该步骤使用已安装的匹配 helper，先读取原生状态，仅在尚无身份时初始化。重复执行保持已有身份；不要反复直接调用原生 `--init`。此步骤不打开发布门禁、不上传。若身份状态异常，保留现场并排查，不能重建身份来跳过错误。

## 6. 两台设备的凭据与配对

没有坚果云账号时，先在[坚果云官网](https://www.jianguoyun.com/)由本人注册并完成验证；已有账号直接登录。Agent 可以打开官网、说明步骤，账号密码与验证码由本人操作。

按[坚果云官方应用密码说明](https://help.jianguoyun.com/?p=2064)，网页右上角账户名 → 账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码。分别创建便于辨认的 `Account Preview 电脑` 与 `Account Preview 手机`；手机坚果云客户端也可在设置 → 第三方应用管理中创建。

在两端 Account Preview 的“同步连接”表单填写账号与应用密码。坚果云 WebDAV 地址已由 App 内置，无需另填：

| 字段 | 填写内容 |
|---|---|
| WebDAV 地址（App 内置） | `https://dav.jianguoyun.com/dav/` |
| 账号 | 本人的坚果云账号邮箱 |
| 应用密码 | 刚为当前设备生成的应用密码 |

地址和账号口径见[坚果云官方 WebDAV 示例](https://help.jianguoyun.com/?p=5677)。应用密码不同于网站登录密码；Agent 不代读密码或截图。需要重新生成时先明确对应设备，更新该设备的设置，不重建账本身份。页面位置可能变化时以官网现有说明为准。

你分别在**电脑和手机** App 原生设置中填写坚果云 WebDAV 信息，每台设备使用各自的应用密码；桌面的密码不会通过配对二维码传到手机。Agent 不接收、读取或记录密码，配对二维码/截图不进入聊天。

身份就绪后，由你在电脑显示配对二维码，手机扫码。每位用户建立独立身份，不复用他人密钥或配对。确认两端设置与配对完成，再进入首次同步。

## 7. 首次授权云端同步

发布同时受原生主门禁和本地发布配置控制。只有用户已授权本次测试同步时，才执行：

```text
PY bootstrap.py --apply --enable-publish
PY scripts/account.py --root ROOT refresh --apply
```

第一条幂等地开启原生门禁，并将本机 `.runtime/ledger/publish.json` 的 `enabled` 设为 true，本身不上传。第二条重建并加密发布空账本快照，必须检查原生云端回读结果。然后由你在手机刷新，核对实际读取结果。

首次云端发布是单独的实际操作权限；若用户已明确授权这次配置包含测试同步，直接连续完成，不重复确认。尚未授权时可完成此前本机准备，将云端步骤明确列为待操作。Android 只读快照、可投递原账单，正式入账仍需电脑审核。
