# 电脑设置视觉与状态验收（2026-11-02）

本轮按维护者要求优化电脑设置，并在现有本机候选上覆盖验证。保持产品版本 0.4.0-preview.3、内部安装版本 0.4.3；没有新建 Release、标签或推送。运行时代码固定于 `df845b7`，本机使用目录和 preview 安装身份保持。

## 页面与行为

- 左侧分类加入与账单工具栏一致的线性图标、选中状态和固定导航；右侧统一圆角、细边框、间距、标题与按钮。
- 一般设置提供浅色、深色和跟随系统的外观缩略预览。高级与诊断沿用同一表单和分组风格。
- 四池预算使用两列编辑区和原有资金池颜色；生效月、修改理由分组，预览与重新读取并排。预算计算、预检、确认与审计流程保持。
- 凭据状态尚未读取时不显示登录表单；已配置时默认收起，点击更换才展开，可取消。配置存在不代表云端已连通。
- 启动读取完成、进入同步分类和窗口回到前台时更新本机状态；连接状态读取失败显示错误与重试。检查云端的进度与结果在设置页内可见。
- 电脑本机快照与云端缓存分别标注；修正本机读取成功后仍残留“尚未同步到任何账单版本”的过期提示。电脑保存凭据不再隐式触发手机自动获取流程。

- App 19 个测试文件、209 项测试通过，TypeScript/Vite 构建与 Windows NSIS 优化构建通过。

- 合成数据浏览器验证明暗主题、800 像素窗口、五个分类以及凭据展开/取消；无横向溢出，未执行发布或获取云端数据。
- 实际覆盖电脑 App 后打开主页与设置，确认已配置状态、默认收起输入框、展开/取消和实际四池编辑区。未提交凭据、修改预算、展示配对二维码或点击云端检查/发布。
