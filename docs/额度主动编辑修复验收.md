# 额度主动编辑修复验收（2026-11-02）

> 历史资料。保留当时的计划、版本和验收范围，后续状态以实际发布/安装证据为准。当前操作入口见[文档导航](README.md)。

用户报告点击额度输入框跳进资金池详情，并要求默认只读、主动修改才显示输入框，视觉细节由 Agent 完成。本轮运行时代码固定于 `4c4071f`，保持 0.4.0-preview.3 / 内部 0.4.3；本机覆盖安装，不创建 Release、标签或推送。

## 根因与改动

预算卡片错误复用 `data-pool` 作为配色标记，主页面委托点击将卡片内输入点击当成资金池导航。预算改为专用 `data-budget-color`，资金池路由只匹配实际 `button[data-pool]`。

常态显示月份与四池普通金额文本，仅保留“修改额度”。点击后进入同页编辑，仅出现月份、金额、下一步和取消。下一步在原设置页展示新旧额度和影响月份；本人明确保存后重新锁定。取消或离开预算分类丢弃草稿。界面删除修改理由，程序记录本人在电脑设置中确认调整的审计依据；保留原预算预检、哈希校验、备份与事务保存通道。
