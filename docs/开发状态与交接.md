# 开发状态与交接

本页提供开发续接时的核对方法。具体任务状态、实验过程、设备回执和历史验收材料保存在本机忽略的 local。公开文档中的功能与兼容说明以相应固定源码为准。

## 开始任务时核对

| 信息 | 取得依据 |
| --- | --- |
| 当前源码与已有修改 | 实际分支、完整提交和工作区状态 |
| 已发布程序 | 对应 tag、Release、发布索引与组件哈希 |
| 下一轮开发基线 | dev 的实际提交及尚未合入的改动 |
| 候选是否冻结、修复是否回流 | 本次获准范围、分支关系和提交差异 |
| 已安装组件与设备结果 | 对应使用根的实际状态和安装回执 |
| 本机任务停点 | 已有 local 开发记录、恢复日志和本次授权 |

公开版本来源、实际设备状态与本机操作结果分别核对。旧摘要只作为线索，关键状态以实际来源确认。

## 选择正式入口

- 开发与验证按[开发指南](开发指南.md)。
- 分支、固定提交及独立版本按[版本与分支管理](版本与分支管理.md)。
- 跨组件改动按[架构与部署边界](架构与部署边界.md)及受影响的数据契约。
- 构建与交付按[开发同步与发布规范](开发同步与发布规范.md)，公开交付逐项核对[发布检查](发布检查.md)。
- 已安装项目的升级和衔接按[更新与恢复](更新与恢复.md)及[版本衔接指引](版本衔接指引.md)。

## 任务收尾

更新持续适用的接口、兼容约束和通用操作文档。把本轮来源提交、验证结果、未执行项、设备状态、恢复位置和后续步骤记入本机 local，关联实际证据。

验证后精确提交本次相关文件，安装、远端推送与公开发布按本次实际授权执行。审阅草稿和本机过程记录使用忽略目录保存。
