# 版本发布说明模板

参照本模板，在本机忽略目录 `local/release-notes/版本.md` 由 Agent 根据实际变更与验证结果起草，再交维护者润色或确认最终稿。原稿仅用于 Release 正文，不作为附件上传。不要直接把模板交给发布工具；工具会拒绝模板路径和占位文字。初稿不等于发布授权，正式发布使用本人确认后的最终文案。

## 流程变更（仅在本版改变更新流程时保留，放在最前面）

若本版改动了 `docs/更新与恢复.md`、官方 Skill 处理、helpers 布局、安装步骤或 `releaseDocs` 路径，本节必须放在“本次更新”之前，并写明：

- 旧文档或旧更新器不能指导本版；先读取本版 `releaseDocs` 的《更新与恢复》和《版本衔接指引》，再执行升级；
- 需要先更新工具或文档再继续的步骤与顺序；
- 桌面与 Android 各自的差异。

没有流程变化时删除本节，不要写“无”。
