# Account

Account 是一个以 Agent 为中心的记账系统。让 Agent 帮你整理、审核和录入账单，再在 App 上优雅地查看收入、支出和分类明细。

账本保存在电脑本地的 SQLite 数据库中，预算和手机同步可以按需启用。

**源码版本为 0.4.0，可下载版本以发布页为准。**

[下载发布版](https://github.com/Milozpace/Account-Preview/releases) · [开始使用](docs/开始使用.md) · [更新已有安装](docs/更新与恢复.md)

## 为什么使用这个系统？

- **优雅记账**。手动逐笔录入坚持不下去，但是常见的自动分类也只是分了个寂寞，还会有各种广告会员什么的……而使用Agent的好处在于，它在完成高效自动录入与自动分类的同时，还可以进行灵活的调整和学习用户习惯，可以让每一个账单都拥有记忆。

- **让 Agent 理解账单背后的用途**。Agent 可以结合原始记录、上下文和你的补充来审核分类，把你确认过的长期偏好保存在本地账单，供后续记账参考。有疑问的记录会留待确认，你也可以随时纠正。

- **App 可视化数据**。Agent维护账本，而App 负责把收支、分类、预算和明细呈现出来。可以非常直观地看出钱花在了哪里，同时前端设计也非常简约舒适

## 你可以用它做什么

- **整理账单**。由 Agent 审核从支付宝、微信导出的 CSV 或 XLSX 流水文件，识别收入、消费、退款、转账等事件，完成归类和入账，并保留原始文件与审核记录。

- **查看收支**。在电脑 App 中按月查看收入、净消费、分类汇总、消费日历和交易明细。

- **按需设预算**。可以为运行、随心、旅行和成长四个资金池设定额度，查看各池消费及预算使用情况。也可以先观察支出，等有需要时再设预算。具体方式见[四池预算设置](docs/四池预算设置.md)。

- **手机同步数据及查看**。Android 配对并配置同步后，可以查看电脑账本的展示快照，也可以用 App 内置功能上传账单原文件，由电脑端 Agent 收取、审核后写入账本。

- **导出月度账单**。在 App 中选择月份，将汇总和明细保存为 Markdown 文件，方便复盘或继续交给 Agent 分析。

## 第一次使用

准备一台受支持的电脑、一个能读取本地文件并执行命令的 Agent，以及你想整理的一个月账单。本地使用无需注册坚果云账号，记账 Skill 随仓库提供。

1. **配置电脑**。按[开始使用](docs/开始使用.md)选择一个长期保留的本地目录，让 Agent 准备项目环境、安装桌面 App 并绑定账本目录。

2. **导入一个月的账单**。告诉 Agent 本次要处理的月份和文件。Agent 使用仓库随版提供的[记账 Skill](.agents/skills/account-maintenance/SKILL.md)审核、入账并核验结果。

3. **打开 App 查看结果**。先核对收支、分类和待确认的交易。想设额度时，再阅读[四池预算设置](docs/四池预算设置.md)。

你可以把下面这段话发给你的 Agent。

> 请帮我配置 Account Preview，仓库地址为 https://github.com/Milozpace/Account-Preview 。先读《开始使用》和 `AGENTS.md`，确认安装目录和已发布版本，完成电脑端配置。然后让我选一个月的本地账单，按随版记账 Skill 审核导入，并在桌面 App 中核对结果。

（可选）*想在 Android 上查看账本或上传账单时，再按[手机与同步](docs/手机与同步.md)配置坚果云和配对，跟着 Agent 的引导一步步操作即可。*

- **手机端的核心**。方便随时查看账本，也方便把原始账单上传到电脑，而不是文件传输助手大法（笑）。

- **关于配置**。第一次配置建议预留半小时左右，实际时间会受下载速度、电脑环境和是否连接手机影响。配置完成后，日常通常就是导出账单、让 Agent 记账，再打开 App 查看，使用起来会轻松很多。

## 软件版本更新方式

电脑端更新时，可以直接和 Agent 说下面这段话。

> 帮我把 Account 更新到最新已发布的最新版本。按照约定的更新操作文档《更新与恢复》和最新发布页的说明内容，完成更新。

Agent 的更新入口见[更新与恢复](docs/更新与恢复.md)。更新后还需要读取目标版本的[版本衔接指引](docs/版本衔接指引.md)，检查适用事项。

手机端目前需要从发布页下载与电脑端同版的 Android ZIP，解压后安装其中的 APK（后续可能优化）（但其实也不麻烦）

## 数据与隐私

- 原始账单、SQLite 账本和个人记账偏好默认**保存在本机**。

- 若你使用的 Agent 调用云端模型，它读取的内容可能按该 Agent 的产品和设置发送给模型服务商。具体处理和保留方式取决于所选服务。我个人可以接受这种使用方式，但是否接受，还是由你自己决定（笑）。

- 配置手机同步功能后，账本展示快照通过坚果云加密同步。你主动从手机上传的账单文件也会加密上传到坚果云。详见[同步与隐私](docs/同步与隐私.md)。
